# Third-party data notice

OctantFake is assembled from COSMOS, DGM4, MEIR, MMFakeBench, NewsCLIPpings, VERITE, Factify,
MS-COCO, OpenImages, DF2023, Fakeddit, PS-Battles, FakeNewsNet, LIAR, PolitiFact, and WELFake.
These sources include multiple licenses, access conditions, and categories of third-party content.

The repository's MIT license applies only to original code and documentation. It grants no additional
rights to dataset images, captions, articles, names, logos, annotations, or model outputs. The
separate dataset package is supplied for research reproducibility under its data terms; users remain
responsible for reviewing and complying with every applicable upstream license and restriction.

The core release excludes web-search caches, downloaded search-result images, raw provider responses,
credentials, local paths, and model weights. Search evidence should be collected or shared separately
only when provider and content terms allow it.

If a rights holder identifies an item that should be restricted or removed, report it through the
dataset repository with the stable `sample_id`, the nature of the concern, and supporting information.
The maintainers can trace public IDs without exposing legacy filesystem names.
